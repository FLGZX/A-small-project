Error Response:
﻿
After entering the "Pets" folder, run the app.py file (use Python IDLE with version 3.12, which can be downloaded from the official Python website).
﻿
If you get an error saying Flask is not installed, open the Command Prompt window by pressing Win + R, type cmd, and run the following command to install Flask:
pip install Flask
(Ensure you are using Python version 3.12.)
﻿
If you receive an invalid IP address error, open Command Prompt and run the command ipconfig. Look for the IPv4 address under "Wireless LAN adapter WLAN". Copy that address, then go to the last line of app.py and paste the IP address inside single quotes to resolve the issue.
﻿

Work Introduction:
﻿
The title of this project is Pets.
It is a local area network (LAN) based web server.
The purpose is to allow users to upload their pet's information to the server and share it with trusted partners within the same LAN.
It supports naming pets, uploading images, and local storage functionality.
﻿
Usage:
﻿
After ensuring that the app.py server launcher is running (and confirming it is functioning properly),
enter the following address in any browser:
current IP address:port number
The website will then run normally.
